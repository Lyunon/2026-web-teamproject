# Google 회원가입 적용 안내

## 변경된 흐름

Google 로그인 → 서버에서 `users/{uid}` 조회 → 프로필이 없으면 `signup.html` → 닉네임 등록 → 사건 목록.
기존 가입자는 바로 사건 목록으로 이동합니다. 가입 화면을 닫은 사용자는 다음 로그인 때 다시 등록합니다.
조회 실패는 미가입으로 처리하지 않으며, 안내 메시지를 표시합니다.

닉네임은 한글 완성형·영문·숫자·밑줄 2~12자입니다. 앞뒤 공백을 제거하고 NFC로 정규화합니다.
중복 닉네임은 허용합니다. 사용자는 Firebase UID로 구별합니다.
문서는 `nickname`, 서버 시각 `createdAt` 두 필드만 저장하며, 비밀번호나 이메일을 별도로 저장하지 않습니다.
동시 등록은 트랜잭션으로 처리하고, 이미 만들어진 문서는 덮어쓰지 않습니다.
이번 작업에서는 닉네임 수정/탈퇴를 제공하지 않습니다.

## Firebase 설정 (프로젝트 관리자 작업)

1. 기존 Google 로그인과 **동일한 Firebase 프로젝트**를 사용합니다.
   `public/js/firebase-config.js`의 설정은 변경하지 않았습니다.
2. Firebase Console → Firestore Database에서 기본 `(default)` 데이터베이스를 준비합니다.
   이미 있으면 그대로 사용합니다. 회원가입 전에 users 컬렉션이나 문서를 수동 생성할 필요는 없습니다.
3. `firestore.rules`의 `match /users/{uid}` 블록을 기존 Firestore 규칙의
   `match /databases/{database}/documents` 안에 병합하고 게시합니다.
   **기존 랭킹 등 다른 컬렉션의 규칙을 파일 전체로 덮어쓰지 마세요.**
   기존의 전체 경로 허용 규칙(`/{document=**}` 등)이 users에도 적용되면 제한 규칙이 무효화될 수 있습니다.
   이 경우 기존 허용 범위를 해당 컬렉션으로 좁혀야 합니다.
4. Google 로그인 제공자와 로컬/배포 주소의 승인된 도메인을 확인합니다.
5. 규칙 게시 전에는 회원 조회가 permission-denied로 실패할 수 있습니다.
   권한/네트워크 오류가 발생하면 게임 진입을 중단합니다. 테스트 모드의 전체 공개 규칙으로 해결하지 마세요.

## 실제 확인 순서

- 터미널에서 `node server.mjs` 후 `http://localhost:3000/` 접속.
  이 명령은 로그인/가입 화면 점검용입니다. Gemini 게임 실행은 별도로 `.env`와 API 키가 필요합니다.
- 처음 사용하는 Google 계정으로 로그인 → 수사관 등록 화면 표시.
- 닉네임을 입력하고 등록 → 사건 목록에 닉네임 표시.
- Firestore에서 해당 UID의 문서와 서버 시각 확인.
- 로그아웃 → 다시 로그인 → 등록 화면 없이 사건 목록 이동.
- 회원 프로필이 없는 다른 계정으로 가입 화면에서 나갔다가 다시 로그인 → 등록 화면 표시.
- 로그아웃 상태에서 cases.html / play.html / result.html 직접 접근 → 로그인 화면 이동.
- 가입 저장 실패 시 입력값 보존, 재시도 가능 여부 확인.
- 다른 계정의 users 문서 조회/생성, 회원 목록 조회, 추가 필드 쓰기가 규칙에 의해 거절되는지 확인.

## 자동 검증

Node.js 20 이상에서:

```bash
npm run test:signup
```

외부 SDK/DB를 대체한 16개 회귀 테스트입니다. 최초/기존 로그인, 가입 중단 재진입,
입력 검증, 조회/저장 오류, 동시 등록의 기존 데이터 보존, 계정 변경, 접근 차단, 로그아웃을 검사합니다.
실제 Google 팝업, 운영 Firestore 규칙, 브라우저 레이아웃은 별도 확인 대상입니다.

## 팀 작업 범위

- 실제 로그인 코드는 `auth.js`와 `firebase-config.js`를 공통으로 사용합니다.
  `firebase.js`는 기존 모듈을 위한 함수명 연결만 남겼습니다.
- 네이버 버튼·스타일·로그인 함수 제거. 옛 auth-complete 주소는 Google 로그인 화면으로 이동합니다.
- `test/detective-visual-scene-v5`는 이전 참고 자료로 변경하지 않았습니다.
- 결과 랭킹은 아직 샘플 데이터입니다. 본인 행에는 등록한 닉네임을 표시하지만 DB에 점수를 저장하지 않습니다.
- 브라우저의 가입 확인은 화면 흐름을 위한 것입니다. 게임 API의 서버 인증/프로필 검사와
  점수 검증은 별도 작업이며, 이 변경이 API 접근까지 보호한다고 가정하면 안 됩니다.
- Firebase 규칙 게시, 실제 로그인 테스트, GitHub 커밋/푸시/PR은 아직 수행하지 않았습니다.
